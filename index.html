Cloud Sync

Keep your binders in sync across devices using a private GitHub gist in your own account. There's no server: data goes straight from this page to GitHub.

1. Create a token (classic, with only the gist permission).
2. Paste it below, here and on each device you use.

The token is stored in this browser only. Use one with just the gist permission, and don't connect on a shared computer.

Changes sync automatically a few seconds after you make them, and when you return to this tab. Every save is kept in the gist's revision history on GitHub.
